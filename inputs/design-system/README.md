# Supplied design-system sources

This folder is an intake area, not an editing workspace.

- `archives/` contains exact copies of the three packages supplied for Phase 1.
- `source/` contains the token JSON extracted without changing its values or names.
- Selected font files used by the local prototype live in `public/fonts/`.

Do not edit the source JSON in place. Map it into code through `src/styles/tokens.css` and document any interpretation in `docs/design-system/DESIGN_SYSTEM_MAPPING.md`.

The Inter license is included with the served font files. The Vazir archive did not include a license file; usage rights must be confirmed before production distribution.

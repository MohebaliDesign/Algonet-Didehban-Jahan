# Phase 1 scope record

## Included

- Safe local Git repository foundation.
- React/TypeScript prototype scaffold and routing.
- Organization design-token and font intake.
- Persian-first RTL and English LTR foundation.
- Light/dark CSS-variable themes.
- shadcn-style editable primitives and Iconsax icons.
- Typed roles, entities, mock data, and service contracts.
- One foundation diagnostic screen.
- Formatting, linting, type checking, unit testing, build, and visual review.

## Deliberately excluded

- Product pages, dashboards, maps, charts, or final navigation.
- Real authentication or permission enforcement.
- Real organizations, users, sources, events, reports, or ingestion jobs.
- Database, API, crawler, AI, or monitoring providers.
- Deployment, hosting, infrastructure, or remote repository creation.
- Final chart/map/status palettes and final product component styling.

The diagnostic screen is a test fixture. It must not be copied into Figma as an approved product page.

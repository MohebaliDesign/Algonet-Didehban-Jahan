# Phase 2 Visual MVP scope

## Included

- Stable Persian-first application shell with mirrored English behavior.
- Seven meaningful product routes plus the preserved `/foundation` diagnostic.
- Context filters, search, development role switching, theme/language switching, notifications/saved affordances, and mock synchronization status.
- Map-first World Monitor with local layers, markers, clustering example, timeline, legend, zoom/reset, Inspector selection, and list alternative.
- Shared module frame, trust footer, data states, AI action, Inspector, charts, dense tables, and prototype feedback.
- Edit Layout mode with reorder, resize, collapse, expand, reset, and local page/role persistence.
- Deterministic local data for events, sources, countries, corridors, markets, forecasts, and reports.
- Viewer-restricted Data Management and an authorized data-manager view.

## Prototype boundaries

No authentication, API, database, crawler, ingestion, AI model, export generator, map provider, deployment, or production authorization has been added. Every operational or AI output is deterministic local demonstration data. Buttons that imply a backend operation explain their prototype-only result.

## Review focus

The implementation is intended to validate information architecture, priority, navigation, role separation, evidence inspection, bilingual directionality, visualization semantics, and module behavior before recreation in Figma. It is not a production implementation or a validated intelligence source.

# Highcharts Maps boundary

The World Monitor and Security & Geopolitics maps use the official `highcharts` package and the Highcharts Map Collection interaction model. The approved world TopoJSON is stored locally at `public/world.topo.json`; it is the same `World, medium resolution` / Map Collection `2.3.3` topology supplied for the map redesign, so the initial world view does not depend on a remote geography request.

The shared implementation lives in `src/components/product/MapCollectionDrilldownMap.tsx`. The top-level world series is built from every geometry in the local topology and uses the collection metadata (`hc-key`, `hc-a2`, `iso-a2`, `iso-a3`, country name, and label metadata). Country fills represent the prototype tension index rather than population. Areas without a local tension fixture keep the tinted map-foundation/no-data color instead of receiving invented intelligence values or rendering as raw white/black.

Country selection follows the Highcharts Map Collection Overview pattern: each world point exposes a drilldown key, the Highcharts drilldown module performs map zooming, and the component resolves the matching Map Collection country TopoJSON from the pinned `2.3.3` `map-index.json`. Country subdivision geometry is fetched only after a user drills into a country. A direct `countries/{hc-key}/{hc-key}-all.topo.json` path is retained as a fallback when index-name matching is unavailable. Every world geometry remains interactive even when no tension fixture exists; maps that have no detailed collection entry remain at the world level and show a short unavailable state.

The repository currently has country-level tension fixtures but does not contain verified province/state-level tension data. To exercise the full subdivision choropleth interaction in the prototype, subdivision values are deterministic mock values derived from the selected country's prototype tension score and are explicitly labeled as prototype subdivision data in the tooltip. They must be replaced by real subnational event aggregation before production use.

The World Monitor restores the operational overlays from the earlier map: filtered intelligence events are rendered as clustered `mappoint` markers, monitored corridors use `mapline`, and the active layer selection filters those overlays and contributes a bounded event-pressure adjustment to the displayed prototype tension score. Event and route overlays are hidden while a country drilldown is open and restored on drill-up so subdivision reading remains clear.

Time and layer controls are product UI rather than Highcharts chrome. `MapOverlayControls.tsx` provides the always-visible UTC date/time chip and a compact shadcn `Popover` layer control composed from `Button`, `Badge`, `InputGroup`, `Checkbox`, `Label`, and `ScrollArea`. The layer surface is collapsed by default to protect map readability, preserves the active-layer count on the trigger, and remains searchable when opened. Security & Geopolitics uses the same compact UTC context while its existing continent `Select` remains the page-specific geographic filter.

Highcharts Maps owns geographic geometry, tension choropleth rendering, country/subdivision data labels, hover emphasis, event clustering, corridor lines, map navigation, smooth map drilldown/drill-up, breadcrumbs, accessibility metadata, legend, and map tooltips. World Monitor retains a non-map list alternative for accessibility and small-screen use. Surrounding page layout, global filters, module controls, and product routing remain outside the map engine and continue to use existing shadcn components and Didehban tokens.

Responsive behavior is container-first: map width remains fluid and constrained to its module; small screens reduce map height and map padding, move the persistent UTC chip away from the map/list control row, keep the layer control collapsed behind a 40px shadcn trigger, and allow the layer popover to fit within the viewport. Highcharts responsive rules move the tension legend to a horizontal bottom layout on narrower containers. These adaptations preserve access to the same map content and filters rather than creating a separate mobile feature set.

Typography follows the product contract: Latin/English labels use Inter and Persian interface/tooltip text uses Vazir. The map foundation and ordered tension colors use the provisional visualization tokens documented in `VISUALIZATION_SEMANTICS.md`; the world SVG reference's `0.72` border weight is retained as the baseline geographic boundary weight.

Country, event, and derived subdivision values are deterministic prototype fixtures. They are not live or verified intelligence. Visualization and risk variables remain provisional where identified in `VISUALIZATION_SEMANTICS.md`.

Highcharts licensing must be validated before any commercial or production release. This repository does not contain a license key and does not suppress required credits. The current use is limited to local evaluation and MVP prototyping.
